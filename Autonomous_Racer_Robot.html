Microcontroller · Brain

Arduino UNO

ATmega328P Microcontroller Board

The central brain of the robot. Reads ultrasonic distance values, executes avoidance logic, and outputs motor drive commands.

16 MHz Clock 5V Operating 14 Digital I/O (6 PWM) 32 KB Flash USB Programmable

What is it?

A microcontroller board based on the Microchip ATmega328P. It includes digital and analog pins, a USB interface, and an onboard voltage regulator.

Why do we use it?

Easy to program via Arduino IDE, reliable, widely supported with tutorials, and has just the right number of pins for 3 ultrasonic sensors (6 pins) + L298N motor driver (4 pins).

Sensors · 3-Way Radar

HC-SR04 Ultrasonic Sensors ×3

Acoustic Distance Sensors (Left, Center, Right)

Three ultrasonic sensors arranged in a 3-way radar configuration (Left, Center, Right) providing real-time distance scanning for intelligent obstacle avoidance.

2–400 cm Range 3 mm Precision 40 kHz Ultrasound 15° Cone Angle 5V Operating

What is it?

An acoustic sensor that emits a 40 kHz ultrasonic burst from one transducer (TRIG) and measures how long it takes for the echo to return to the other (ECHO). Distance = (Time × 0.0343) / 2.

Why do we use it?

Three sensors give 180-degree forward awareness without moving parts: Center detects dead ahead, Left checks left clearance, Right checks right clearance — allowing intelligent navigation decisions.

Driver · Dual H-Bridge

L298N Motor Driver Module

Dual H-Bridge High-Power DC Motor Driver

Amplifies low-current logic signals from the Arduino to control speed and direction of the BO DC gear motors via two H-bridge channels.

2A Peak per Channel 5V–35V Motor Power 5V Onboard Regulator Independent Speed/Dir Screw Terminals

What is it?

An H-bridge driver IC mounted on a breakout board with heatsink, flyback diodes, screw terminals, and a 5V regulator. It switches high battery current using low-current logic inputs.

Why do we use it?

Microcontrollers cannot supply the high current needed by DC motors. The L298N handles the current demands safely while allowing precise speed control via Arduino PWM pins.

How the Robot Works

The robot continuously reads its three ultrasonic sensors and uses that information to steer its 4WD drivetrain away from obstacles.

Ultrasonic Sensors
↓
Arduino UNO
↓
Decision Logic
↓
L298N Motor Driver
↓
BO DC Gear Motors
↓
Robot Movement

Sensor Positions

LEFTTRIG D2 / ECHO D3
CENTERTRIG D4 / ECHO D5
RIGHTTRIG D6 / ECHO D7

The center sensor detects obstacles directly ahead. The left and right sensors detect obstacles on either side in the angled bumper.

Decision Rules (from the code)

  • Front Obstacle (Center < 15 cm): Compare clearances and steer towards the open side — if Left > Right, pivot turn left (left 0, right 255); if Right > Left, pivot turn right (left 255, right 0).
  • Left Obstacle Evade (Left < 17 cm): Pivot turn right (left 200, right 0 PWM).
  • Right Obstacle Evade (Right < 17 cm): Pivot turn left (left 0, right 255 PWM).
  • Clear Path: Move forward at full speed PWM 255 on all four wheels.

🧮 Autonomous Decision Matrix

Real-time obstacle evaluation matrix executed in the 50 ms loop in autoracerl298n.ino:

Sensor Condition Distance Threshold Robot Behavior Left Motors (OUT1/2) Right Motors (OUT3/4)
Path Ahead Clear Center ≥ 15 cm, Left & Right ≥ 17 cm Cruise forward at full speed FORWARD (255) FORWARD (255)
Obstacle on Left Left < 17 cm, Right ≥ 17 cm Pivot turn right FORWARD (200) STOP (0)
Obstacle on Right Right < 17 cm, Left ≥ 17 cm Pivot turn left STOP (0) FORWARD (255)
Front Obstacle / Corner Center < 15 cm Compare clearance & steer away (Left > Right: Turn Left, Right > Left: Turn Right) If Left > Right: STOP (0)
If Right > Left: FORWARD (255)		 If Left > Right: FORWARD (255)
If Right > Left: STOP (0)

Arduino Program

Upload this program to the Arduino UNO using the Arduino IDE. Built entirely with standard built-in Arduino functions — no external libraries required.

Autonomous_Racer_Robot.ino 

// Motor Driver Pins (PWM pins on Uno: 3,5,6,9,10,11)
const int IN1 = 9;   // Left motor speed
const int IN2 = 8;   // Left motor direction
const int IN3 = 11;  // Right motor speed
const int IN4 = 12;  // Right motor direction (D12)

// Ultrasonic Sensor Pins
const int trig1 = 2;  const int echo1 = 3;   // Left sensor
const int trig2 = 4;  const int echo2 = 5;   // Center sensor
const int trig3 = 6;  const int echo3 = 7;   // Right sensor



const float MAX_SENSOR_DISTANCE       = 200.0;  // cm
const float FRONT_OBSTACLE_THRESHOLD  = 15.0;   // cm - center sensor triggers backup + turn
const float SIDE_OBSTACLE_THRESHOLD   = 17.0;   // cm - left/right sensors trigger turn
const unsigned long SENSOR_INTERVAL   = 50;     // ms between sensor reads
const unsigned long BACKUP_DURATION   = 220;    // ms to reverse when front obstacle detected

unsigned long lastSensorReadTime = 0;

// ==========================================
// MOTOR CONTROL
// ==========================================

void motor1(int speed) {       //Left Motor speed
  if (speed > 0) {
    digitalWrite(IN1, LOW);
    analogWrite(IN2, speed);       // Forward
  } else if (speed < 0) {
    digitalWrite(IN1, HIGH);
    analogWrite(IN2, speed);      // Backward 
  } else {
    digitalWrite(IN1, HIGH);
    analogWrite(IN2, HIGH);           // Stop
  }
}

void motor2(int speed) {      //Right Motor speed 
  if (speed > 0) {
    digitalWrite(IN3, LOW);
    analogWrite(IN4, speed);       // Forward
  } else if (speed < 0) {
    digitalWrite(IN3, HIGH);
    analogWrite(IN4, speed);      // Backward (negate to get positive PWM value)
  } else {
    digitalWrite(IN3, HIGH);
    analogWrite(IN4, HIGH);           // Stop
  }
}

void motorControl(int leftSpeed, int rightSpeed) {
  motor1(leftSpeed);
  motor2(rightSpeed);
}



void setup() {
  Serial.begin(9600);

  // Ultrasonic pins
  pinMode(trig1, OUTPUT); pinMode(echo1, INPUT);
  pinMode(trig2, OUTPUT); pinMode(echo2, INPUT);
  pinMode(trig3, OUTPUT); pinMode(echo3, INPUT);

  // Motor pins
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);

  motorControl(0, 0); // Start stopped
  Serial.println("Robot Ready!");
}


void loop() {
  unsigned long currentMillis = millis();


  if (currentMillis - lastSensorReadTime >= SENSOR_INTERVAL) {
    lastSensorReadTime = currentMillis;

    float leftDist   = getDistance(trig1, echo1);
    float centerDist = getDistance(trig2, echo2);
    float rightDist  = getDistance(trig3, echo3);

    Serial.print(leftDist);
    Serial.print("       ");
    Serial.print(centerDist);
    Serial.print("       ");
    Serial.println(rightDist);


    if (centerDist < FRONT_OBSTACLE_THRESHOLD) {
      // Back up briefly, then turn left for the same duration

      if(leftDist>rightDist){
        motorControl(0, 255);
      }
      else if(rightDist>leftDist){
        motorControl(255, 0);
      }
    }
    else if (leftDist < SIDE_OBSTACLE_THRESHOLD) {
      motorControl(200, 0);  // Turn Right in place
    }
    else if (rightDist < SIDE_OBSTACLE_THRESHOLD) {
      motorControl(0, 255);  // Turn Left in place
    }
    else {
      motorControl(255, 255);   // Go Forward
    }
  }
}

float getDistance(int trigPin, int echoPin) {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
                                                                                                                                                                         
  long timeout = (MAX_SENSOR_DISTANCE * 2.0 / 0.0343) + 3000;
  long duration = pulseIn(echoPin, HIGH, timeout);

  if (duration == 0) return MAX_SENSOR_DISTANCE;

  float distance = duration * 0.0343 / 2.0;

  if (distance > MAX_SENSOR_DISTANCE) return MAX_SENSOR_DISTANCE;
  if (distance < 0) return 0.0;

  return distance;

}

Assembly & Setup

Follow these steps to build the Autonomous Racer Robot (BO DC Motor Edition).

  1. Prepare the Robot Chassis

    Lay out your robot chassis base and identify the mounting positions for the BO DC gear motors, L298N driver, Arduino UNO, 18650 × 2 battery holder (with ON/OFF switch), and front ultrasonic sensors.

  2. Attach BO DC Gear Motors & Wheels

    Mount the 1:48 single-axis BO DC gear motors securely on the left and right sides of the chassis so all output shafts align horizontally, then fit the drive wheels snugly onto each motor shaft.

  3. Mount Arduino UNO and L298N Motor Driver

    Secure the Arduino UNO and the L298N motor driver module onto the chassis platform using double-sided mounting tape or standoffs, leaving clear access to the Arduino USB port and L298N screw terminals.

  4. Mount the Three Ultrasonic Sensors

    Mount the three HC-SR04 ultrasonic sensors at the front of the robot (Left, Center, Right), ensuring they face horizontally outward with an unobstructed view.

  5. Connect Sensor Wires

    Connect sensor VCC to Arduino 5V, GND to GND, Left TRIG/ECHO to D2/D3, Center TRIG/ECHO to D4/D5, and Right TRIG/ECHO to D6/D7 using DuPont jumper wires.

  6. Connect BO Motor Wires to L298N

    Wire the left BO DC motors to the OUT1 & OUT2 screw terminals and the right BO DC motors to OUT3 & OUT4. Connect L298N logic inputs IN1→D9, IN2→D8, IN3→D11, and IN4→D12 on the Arduino.

  7. Mount 18650 Battery Holder & Connect 7.4V Li-Ion Power

    Keep the battery holder switch OFF while wiring. Secure the 18650 × 2 battery holder to the chassis using heavy-duty double-sided tape. Insert two 3.7V 2900mAh Li-Ion cells observing +/− polarity and close the slide cover. Connect the holder Red wire (+) to L298N 12V, Black wire (−) to L298N GND, and link L298N GND to Arduino GND for common ground. Carefully double-check polarity!

  8. Upload the Arduino Program

    Connect the Arduino to your computer via USB, open autoracerl298n.ino in the Arduino IDE, select Arduino UNO board and COM port, and click Upload.

  9. Test the Robot

    Place the robot on a clear floor, slide the 18650 battery holder switch to ON, and observe it cruising forward smoothly at PWM 255 and steering away from obstacles when detected!

Final Testing Checklist

Go through each item before letting the robot run freely. Click an item to mark it done.

  • Arduino powers on correctly (green LED lit)
  • L298N motor driver power LED lit steadily when battery switch is ON
  • Common ground connected between L298N GND and Arduino GND
  • 2× 18650 Li-Ion cells inserted with correct polarity and holder wires verified (+ Red, − Black)
  • Left BO DC motors rotate forward when commanded
  • Right BO DC motors rotate forward when commanded
  • All BO motors and wheels securely mounted and spinning freely without rubbing
  • Left ultrasonic sensor reports accurate distance on Serial Monitor (D2/D3)
  • Center ultrasonic sensor reports accurate distance on Serial Monitor (D4/D5)
  • Right ultrasonic sensor reports accurate distance on Serial Monitor (D6/D7)
  • Robot cruises forward smoothly at PWM 255 when path is clear
  • Robot turns right when obstacle placed < 17 cm near left sensor
  • Robot turns left when obstacle placed < 17 cm near right sensor
  • Robot compares clearance and steers towards open side when front obstacle is < 15 cm

Safety Notes

⚠️Check battery polarity before connecting it to the circuit. Reversed polarity can permanently damage components.
⚠️Do not short-circuit the battery terminals. Never let bare wires touch both terminals at the same time.
⚠️Do not connect the 7.4V battery directly to Arduino signal or I/O pins. Use the motor driver module's regulated 5V supply path.
⚠️Keep fingers, loose wires, and clothing away from rotating wheels and motors while the robot is powered on.
⚠️Test the robot on a clear, flat surface away from ledges, stairs, and obstacles that could cause it to fall.
